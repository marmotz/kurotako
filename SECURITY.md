# Security Policy

## Supported versions

kurotako is on `0.x`. Only the latest `0.x` release line receives security fixes.

| Version      | Supported |
|--------------|-----------|
| latest `0.x` | yes       |
| older        | no        |

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub:
**[Security → Report a vulnerability](https://github.com/marmotz/kurotako/security/advisories/new)**
(private security advisory).

Please do not open a public issue for security reports.

Include, if possible: affected package (s) and version, a description of the impact, and
minimal reproduction steps. You will get an acknowledgement within a few days.

There is no bug bounty program.
