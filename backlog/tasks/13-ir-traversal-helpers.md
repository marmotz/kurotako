   - `getSource(ir, namespace)`
   - `resolveEntity(ir, namespace, name)`
   - `resolveEnum(source, entity, ref)` — entity-local enums take precedence over
     source-level; single implementation shared by all generators.
   - `resolveRelationTarget(ir, fromNamespace, rel)`
   - `isCrossSource(fromNamespace, rel)`
   - `iterEntities(ir)` — `Iterable<{ namespace; entity }>`
   - `iterFields(entity)` — `Iterable<Field>`

2. Shared-decision helpers (same file), pure + exhaustively switched over the closed
   unions — the single home for rules `gen-zod` and `gen-angular` would otherwise both
   re-encode ([../features/ir-model/technical.md §Shared-decision helpers](../features/ir-model/technical.md#shared-decision-helpers-helpersts)):
   - `isDbAssigned(field)` — `field.default?.kind === 'expr'`.
   - `createFields(entity)` — `entity.fields` minus a primary-key member that is
     `isDbAssigned` (autogenerated key, never in a create payload).
   - `isCreateOptional(field)` — `field.optional || field.default != null || isDbAssigned(field)`.
   - `updateFields(entity)` — `entity.fields` minus primary-key members.
   - `scalarTsType(type: FieldType)` — the closed scalar → TS source-type string mapping
     (`string|uuid|decimal|bytes → 'string'`, `int|float → 'number'`, `bigint → 'bigint'`,
     `boolean → 'boolean'`, `date|datetime → 'Date'`, `json → 'unknown'`,
     `kind: 'enum' → <ref>`, `kind: 'unknown' → 'unknown'`). Nullable / list wrapping is
     the caller's job.
3. `packages/ir/src/helpers.test.ts` — resolution cases (entity-local enum shadowing a
   same-name source-level one; cross-source relation target → `resolveRelationTarget`
   `undefined`, `isCrossSource` true) **plus** a fixture table for the shared-decision
   helpers: `createFields` drops an `@id @default(uuid())`-style field, keeps a
   `createdAt` `expr`-default field but `isCreateOptional` returns true for it;
   `updateFields` drops a composite primary key; `scalarTsType` covers every `ScalarType`
   + enum + unknown.
4. Add `helpers.ts` to the `index.ts` barrel.
5. `bun run typecheck`, `bun run test`, `bun run build` green.
