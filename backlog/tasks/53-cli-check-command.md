## Verified

- [#44](44-cli-scaffold-reporter-errors.md) builds the citty tree in `cli.ts` with a
  shared `sharedArgs` (`config: { type: 'string' }`), `ConsoleReporter implements Logger`
  (stderr, `tako ` prefix), `renderError(e: TakoError)` and the top-level `TakoError`
  catch → `process.exitCode = 1`.
- [#46](46-cli-generate-validate-commands.md) adds `commands/generate.ts` with a
  `loadAndRun({ write })` helper (`loadConfig()` then `run()`), and `commands/validate.ts`
  (`run({ write: false })`).
- [51-core-writer-plan](51-core-writer-plan.md) adds `RunOptions.plan` /
  `RunResult.plan: PlannedFile[]` (`{ path: absolute, content }`); `run({ plan: true })`
  runs steps 1→5c then `selectWriter(output).plan(...)`, skips `afterEmit`, writes
  nothing. [52-output-package-writer-plan](52-output-package-writer-plan.md) makes
  `plan()` total over modes A and B.
- `ResolvedConfig.output` carries `{ mode?, dir?, packagesDir?, scope? }` and
  `ResolvedConfig.rootDir` (absolute config-file dir).

## To do

1. `packages/cli/src/diff.ts`:
   - `export type DriftKind = 'modified' | 'missing' | 'orphan'`;
     `export interface DriftEntry { kind: DriftKind; path: string /* relative to rootDir */ }`.
   - `export async function comparePlanToDisk(args: { plan: PlannedFile[]; roots: string[];
     ignore: (absPath: string) => boolean; rootDir: string }): Promise<DriftEntry[]>`:
     - for each `PlannedFile`: absent on disk → `missing`; `readFile(path,'utf8') !==
       content` → `modified` (exact bytes, no newline leniency); equal → skip;
     - recursively walk each `roots` entry; a regular file not in the planned set and not
       rejected by `ignore` → `orphan`; **collapse** a directory whose whole subtree is
       orphan (no planned file under it) to a single `orphan <dir>/` entry;
     - return entries sorted by `path` then `kind`.
2. `packages/cli/src/commands/check.ts` — `tako check [--config <path>]`:
   - `const { config } = await loadConfig({ cwd: process.cwd(), configPath })`;
   - `const { plan } = await run(config, { logger: reporter, plan: true })`;
   - build `roots` / `ignore` from `config.output`:
     - mode A (`mode` absent / `'dir'`): `roots = [output.dir]`, `ignore` rejects nothing;
       if `output.dir` does not exist at all → print
       `output directory <dir> does not exist — run tako generate` and
       `process.exitCode = 1`, return;
     - mode B (`mode: 'package'`): `roots` = each owned `<pkgDir>` for a namespace in the
       config **plus** any sibling dir under `packagesDir` whose `package.json` carries the
       `"// Generated by tako. Do not edit."` marker but whose namespace is absent from the
       config; `ignore` rejects `**/dist/**` and `**/node_modules/**`;
   - `const drift = await comparePlanToDisk({ plan, roots, ignore, rootDir: config.rootDir })`;
   - empty → `reporter.info('output is in sync')`, `process.exitCode ??= 0`;
   - non-empty → print `drift detected` then one aligned line per entry
     (`<kind>  <path>`), then
     `<n> files differ from a fresh generate. Run \`tako generate\`.`;
     `process.exitCode = 1`.
   - No `--watch`, `--namespace`, `--json`, `--diff`, `--verbose`.
