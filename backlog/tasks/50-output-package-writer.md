## Verified

- [#20](20-core-writer.md) ships `writer/` with `selectWriter` throwing
  `UnsupportedOutputModeError` for `mode: 'package'`; this task flips that branch.
- [#21](21-core-run.md) wires `run.ts` step 6 (`selectWriter(...).write(...)`) and step 7
  (`afterEmit`); [#48](48-output-root-barrel-and-banner.md) adds the synthesized
  `<ns>/index.ts` to the tree the writer receives.
- `collectPeerDependencies` / `resolvePackageManager` / `runInstall` come from
  [#49](49-output-peers-and-pm.md).
- `PackageBuildError` / `PackageInstallError` / `OutputPeerConflictError` are declared by
  [#15](15-core-types-and-contracts.md); `output.scope` / `output.packageManager` reach
  `ResolvedConfig.output` via [#25](25-config-load.md).
- `tsup` is a root devDependency ([#3](3-tsup-build-preset.md)); this task promotes it to a
  `dependencies` of `@kurotako/core`, imported lazily.

## To do

1. `packages/core/package.json`: add `tsup` to `dependencies` (used via
   `await import('tsup')`, mode-B path only — a mode-A run never resolves it).
2. `packages/core/src/writer/package.ts` — `export const packageWriter: Writer`:
   1. group `files` by namespace (first path segment);
   2. per namespace `<ns>`: package dir `<packagesDir>/<scope-without-@>-<ns>/`; refuse a
      non-empty existing dir whose `package.json` lacks the `"//": "Generated by tako…"`
      marker (`OutputNotGeneratedError`, new, extends `TakoError`); otherwise wipe +
      recreate;
   3. write sources under `<pkgDir>/src/` with the `<ns>/` prefix stripped;
   4. emit `<pkgDir>/package.json` — `name: '<scope>/<ns>'`, `version: '0.0.0'` (frozen,
      never bumped), dual `exports` (`"."` + `"./*"` wildcard for the fine-grained
      subpaths), `files: ['dist','src']`, `peerDependencies` from
      `collectPeerDependencies(...)[ns]` (sorted keys), `scripts.build: 'tsup'`,
      `"//": 'Generated by tako. Do not edit.'`; fixed key order;
   5. emit `<pkgDir>/tsconfig.json` (extends `../../tsconfig.base.json`, `outDir: dist`,
      `include: ['src']`) and `<pkgDir>/tsup.config.ts` (re-export `basePreset`, `entry` =
      every `src/**/*.ts`), both with the banner comment;
   6. write `<packagesDir>/.gitattributes` once and `<pkgDir>/.gitattributes` per package;
   7. build: `const { build } = await import('tsup')`, per package
      (`entry: src/**/*.ts`, `format: ['esm','cjs']`, `dts: true`, `outDir: dist`,
      `silent: true`); failure → `PackageBuildError { namespace, cause }`;
   8. install once: `resolvePackageManager({ configured: output.packageManager, startDir: packagesDir })`;
      non-null → `runInstall(pm, workspaceRoot)` (nearest ancestor with `workspaces` /
      `pnpm-workspace.yaml`, else `packagesDir`); null → `warn` the manual command;
   9. return the sorted absolute **source** paths (steps 3–6); never `dist/`.
3. `packages/core/src/writer/index.ts` — `selectWriter`: `mode: 'package'` → `packageWriter`
   (remove the throw); anything other than `'dir'` / `'package'` still →
   `UnsupportedOutputModeError`.
4. `packages/core/src/run.ts` — step 7: `AfterEmitContext.outputDir` = `output.packagesDir`
   in mode B (was always `output.dir`); `files` stays the written source paths.
5. `packages/core/src/writer/*.test.ts` (+ extend the `run` suite; temp dir, tsup build on
   a tiny real fixture or stubbed):
   - one namespace → `packages/<scope>-<ns>/` with `src/` (prefix stripped), `package.json`
     (`name`, `version: '0.0.0'`, sorted `peerDependencies`, `exports`), `tsconfig.json`,
     `tsup.config.ts`, `.gitattributes`;
   - build failure → `PackageBuildError`; install invoked once with the resolved pm and
     workspace-root `cwd`; `PackageInstallError` on non-zero exit; skipped + `warn` when
     the pm is unresolved;
   - a pre-existing unmarked non-empty `<pkgDir>` → `OutputNotGeneratedError`;
   - returned list is sorted source paths, no `dist/`;
   - `run()` mode B: `afterEmit` sees `packagesDir`; `write: false` spawns nothing;
   - determinism: same IR + config → byte-identical `package.json` + barrels on a re-run.
6. `bun run typecheck`, `bun run test`, `bun run build` green.
