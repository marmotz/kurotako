  `directory.ts` / `index.ts` (`selectWriter`). [#21](21-core-run.md) wires `run.ts`
  steps 1–8 and leaves call-site seams for barrel synthesis (5b) and banner (5c).

  `<ns>/index.ts` itself.

  `${ns}.${entity}` with a `symbols` map.

## To do

1. `packages/core/src/writer/banner.ts`:
   - `export const BANNER = '// Generated by tako. Do not edit.\n'`.
   - `export const GITATTRIBUTES = '* linguist-generated=true\n'`.
   - `export function applyBanner(files: VirtualFile[]): VirtualFile[]` — prepend `BANNER`
     to every `.ts` / `.tsx` file; prepend the comment form to `tsconfig.json` /
     `tsup.config.ts` when present; leave `.json` (`package.json`) untouched (the mode-B
     writer sets a `"//"` key instead). Idempotent-safe (never double-prepend). Pure.
   - `directoryWriter` (#20) may import `GITATTRIBUTES` in place of its inline literal —
     optional cleanup, not required here.
2. `packages/core/src/writer/barrel.ts`:
   - `export function synthesizeRootBarrels(files: VirtualFile[], artifactsByGenerator?: Record<string, GeneratorArtifact>, logger?: Logger): VirtualFile[]`
     — for each namespace `ns` (first path segment) present in `files`, collect the
     second-path-segment generator names that emitted ≥ 1 file under `<ns>/<name>/`; emit
     `VirtualFile { path: '<ns>/index.ts', content }` with one **sorted**
     `export * from './<name>'\n` line per contributing generator.
   - A single-generator namespace still gets a root barrel.
   - When `artifactsByGenerator` is supplied, `logger?.warn(...)` if the same identifier
     appears in two contributing artifacts' `entities[*].symbols` for one namespace
     (ambiguous star re-export). Never throws.
3. `packages/core/src/run.ts` — fill the seams from [#21](21-core-run.md):
   - **step 5b**: after `mergeTrees`, append `synthesizeRootBarrels(files, artifacts, logger)`
     to the tree and re-sort by path. A generator that emitted `<ns>/index.ts` itself now
     collides with the synthesized file → `OutputCollisionError`; extend its message to
     name the `<ns>/<generatorName>/` prefix rule.
   - **step 5c**: `files = applyBanner(files)` immediately before `selectWriter(...).write(...)`.
4. `packages/core/src/writer/*.test.ts` (+ extend the `run` suite):
   - `barrel`: two generators on one namespace → one `<ns>/index.ts` with two sorted
     `export *` lines; single generator → still a barrel; same symbol in two artifacts →
     `warn`, barrel still emitted.
   - `banner`: `.ts` gets the line prepended; `package.json` untouched; not double-prepended;
     constant output.
   - `run`: a generator emitting `<ns>/index.ts` → `OutputCollisionError`; the written tree
     contains a synthesized `<ns>/index.ts` and every `.ts` file starts with the banner.
5. `bun run typecheck`, `bun run test`, `bun run build` green.
