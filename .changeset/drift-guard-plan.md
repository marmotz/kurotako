Add the `Writer.plan()` seam and `tako check` drift guard.

`@kurotako/core`: the `Writer` interface gains `plan(input): Promise<PlannedFile[]>` — the
exact files a `write()` would emit (absolute path + bytes, mode B `src/` remap and
synthesized manifest included) with no disk I/O, no tsup build and no `pm install`.
`directoryWriter` and `packageWriter` are refactored so `write()` builds on `plan()`,
keeping the two in lock-step. `RunOptions` gains `plan?: boolean`; `run(config, { plan: true })`
runs the pipeline up to (not including) emission, calls each output's `Writer.plan()`,
skips the `afterEmit` hook, writes nothing, and returns the aggregated, path-sorted
`RunResult.plan: PlannedFile[]`. `PlannedFile` is a new exported type.

`@kurotako/cli`: new `tako check [--config <path>]` command. It runs `run({ plan: true })`
and compares the plan against disk in memory, reporting `modified` / `missing` / `orphan`
files (a wholly-orphan directory collapses to one entry). Exit 0 when in sync, exit 1 on
any drift or any `TakoError`. Mode B ignores `dist/` and `node_modules/` and only scans
package directories carrying the `"// Generated by tako"` marker. `comparePlanToDisk` and
its `DriftEntry` / `DriftKind` types are re-exported from the library barrel.
